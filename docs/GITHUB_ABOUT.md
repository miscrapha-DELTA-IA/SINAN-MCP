# GitHub repository About metadata

This file contains the proposed GitHub **About** settings for SINAN MCP. It is not a substitute for the repository's About panel: editing this file does **not** change GitHub's repository description, website or topics automatically.

## Recommended repository description (English)

> Research-alpha MCP toolkit for SINAN: official-source discovery, reproducible workflows, and synthetic epidemiology demos.

## Descrição alternativa (português)

> Toolkit MCP experimental para o SINAN: fontes oficiais, fluxos de pesquisa rastreáveis e demonstrações epidemiológicas sintéticas.

## Suggested website

https://github.com/miscrapha-DELTA-IA/SINAN-MCP#public-synthetic-preview

This URL leads to the repository's explicitly synthetic public-preview section, rather than implying a validated official data portal.

## Suggested GitHub topics

`model-context-protocol` · `mcp-server` · `epidemiology` · `public-health` · `bioinformatics` · `python` · `sinan` · `datasus` · `open-source`

## Apply in GitHub

On the repository homepage, select the gear icon next to **About** (requires repository write access), paste the English description, optionally set the website, choose the topics above and save.

Do not describe the public endpoint as an official SINAN service, a live surveillance database, a validated clinical system or a production-ready repository. Version is `0.4.0-alpha.4`; experimental functions and PRs should be presented as research work.
